# Glossaire

## Musique et batterie

| Terme | Définition |
| --- | --- |
| Grosse caisse | Le plus gros fût, joué au pied droit avec une pédale |
| Caisse claire | Fût central au timbre claquant, joué aux baguettes |
| Charleston | Deux cymbales superposées, fermées par une pédale (pied gauche) ; jouée fermée, ouverte ou au pied |
| Toms | Fûts accordés (aigu, médium, basse) |
| Crash | Cymbale d'accentuation |
| Ride | Cymbale d'accompagnement, souvent jouée en continu en jazz |
| Groove | Motif rythmique répété qui porte un morceau |
| BPM | Battements (noires) par minute : le tempo |
| Mesure | Groupe de temps (en 4/4 : quatre noires) |
| Croche, double croche | Moitié, quart d'un temps |
| Swing / ternaire | Contretemps joués en retard, typiques du jazz |
| Accent | Coup joué plus fort |
| Note fantôme | Coup très léger, surtout à la caisse claire |
| Étouffement (*choke*) | Coup qui coupe la résonance d'un autre (charleston fermée qui coupe l'ouverte) |

## Technique

| Terme | Définition |
| --- | --- |
| Latence | Délai entre le geste et le son entendu |
| Tampon audio | Bloc d'échantillons préparé d'avance ; plus il est petit, plus la latence est basse |
| Scancode | Code de la position physique d'une touche, indépendant de la disposition (AZERTY/QWERTY) |
| *Ghosting* | Combinaison de touches simultanées qu'un clavier ne sait pas transmettre |
| `HitEvent` | Événement interne « un coup sur tel élément, à tel instant, avec telle force » |
| General MIDI (GM) | Norme qui attribue un numéro de note à chaque élément de batterie |
| UVC | Norme des webcams qui fonctionnent sans pilote |
| Images/s | Fréquence de capture d'une caméra (30 ou 60 en général) |
| HSV | Espace de couleur utilisé pour repérer les embouts colorés |
| ADR | *Architecture Decision Record* : une décision technique par fichier |
| PR | *Pull Request* : demande de fusion d'une branche, relue avant d'entrer dans `main` |
| CI | Intégration continue : tests lancés automatiquement à chaque PR |
